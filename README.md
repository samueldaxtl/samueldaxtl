Atuo na área comercial e desenvolvo ferramentas para reduzir trabalho manual em rotinas de CRM e revisão de dados.

- **Automação comercial** — triagem de leads, deduplicação e conferência de importações.
- **Linux e Python** — ferramentas locais para rodar e testar processos.
- **Git** — código, documentação e histórico de mudanças no mesmo projeto.

### Em desenvolvimento

**Jarbas** é um assistente comercial para cruzar exportações de leads, prospecções e clientes. O MVP roda localmente e gera uma fila com referências às fontes para conferência.

### Como trabalho

Priorizo segurança, estabilidade, simplicidade e escala, nessa ordem. Valido mudanças com dados fictícios antes de aplicar um processo a dados reais.
